# 生产上线闸门

发布候选代码经测试不等于目标基础设施验收。下列必须由实际部署方记录日期、环境与责任人：

1. 在干净主机执行 compose 构建，核对依赖/镜像安全扫描、镜像摘要和许可证；确认 migration一次性成功、zc_app无DDL、资源/名单/审计不可变约束实际在 PostgreSQL 生效。
2. 域名证书与HTTPS；仅80/443开放，数据库和应用端口不暴露；cookie Secure/HttpOnly/SameSite，CSRF与外院/同院未授权访问均被阻断；实际管理员TOTP首次登录、时间同步、恢复演练。
3. ClamAV病毒库可更新，合法上传成功；EICAR标准测试文件或安全扫描测试被拒绝；扫描器停机时上传失败而非放行。不要把扫描测试文件存到业务项目。
4. iOS Safari / Android Chrome、电脑Chrome/Firefox/Edge实际网络访问；HEIC/旋转EXIF/40MP保护/多图重试/相册和拍照；横竖屏与键盘操作；长名单、全量证据、PDF中文渲染。
5. 使用预计峰值人数与材料大小进行上传、并发标注、409重试、计算/公示/导出负载测试。资源配额与导出内存边界明确；不能用单班样本推算校园性能。
6. 在隔离的新环境从同一套数据库dump+objects+APP_SECRET恢复；运行verify；确认导入/备份前后各学生结果、原始材料SHA和公示轨迹一致；记录恢复点/耗时。备份加密、离线保存；不得只备份数据库。
7. 学院确认模板、扣分与封顶顺序、具体岗位权重、课程替代、边界日期、跨年度CSP等规则的正式解释；确认私密个人展示如何与细则要求的班级/学院两轮公示衔接。系统支持多轮快照和交叉审核，但不是对公示制度变更的行政批准。
8. 完整独立复核一批已确定的基准案例，特别抽查Agent“有效”材料。正例抽查可在标注界面筛选有效并抽样；外部Agent识别准确率本次没有测评。
9. 填齐正式学业成绩和品德认定，处理待定及异常；测试工程不复用作正式成绩；导入后的来源确认不等于证明所有材料合法。最后再开启真实用户入口。

本次交付的自动测试结果见 `docs/validation/test-results.xml`；界面测试限制、合成规模、PDF逐页结果与旧工程兼容性汇总在 `docs/validation/`；本轮不重新交付真实资料。未完成项不得勾选“通过”。

10. 在实际Excel／WPS打开多级总表、所有成果、模板与分类表，验收字体、分页、冻结、合并、换行、中文和打印重复标题；最大值原分舍弃、每级小计与服务器轨迹一致。不能用渲染器预览替代实际办公软件。
11. 盖章字段未知不当作无章，公共行与来源覆盖正确；更新后回滚须恢复匹配旧代码的备份。逐角色在HTTPS浏览器下载，包括历史公示不带入后改数据、学生只本人及内部备注隔离。
12. 700人、13300成果串行测试已经执行，但不得据此跳过并发导出时内存、网关超时和CPU验收；按分类拆分过宽Excel，不忽略物理限制。

## rc4新增验收项

- 连续阅卷：固定队列、更新状态后的下一项、最后一项、草稿离开确认、网络失败／冲突、幂等重试、中文输入法与快捷键、只读阶段。
- 集合：本页／跨页范围、Ctrl/⌘／Shift、框选、Esc撤销、双轴滚动、右键及键盘菜单、输入框原生菜单、触屏备用按钮；大量选择再筛选时显示隐藏选择数量。
- 表格：保存前完整诊断与原子回滚、位置准确、公式拒绝、重复及篡改身份、学院权限、版本冲突。先预览后确认，失败不产生部分账号、分数或草稿保存。
- 网页AI：真实任务ZIP下载、当前凭据及模板回填、错误清单修正、840行规模、签名／过期／规则变化／人工处理后拒绝、同任务同内容重试。合成模型结果不作为实际模型准确率测试。
- 截屏：现场浏览器原生屏幕选择器／授权拒绝／取消、立即停止共享、裁剪及整图、屏幕缩放、剪贴板粘贴、桌面与手机回退；本机canvas替身不能替代现场验收。
- 隐私：学生结果API、表格及PDF一致排除内部字段，仅显示本人公示；历史版本不带入后来更改的数据。确认批量账号停用撤销已有会话。
- 源码ZIP：在空目录核对SHA256、编译、CLI与回归；五份HTML离线图片、锚点和运行时副本一致。目标部署还需验证真实HTTPS、cookie、CSRF及反向代理，而非只依赖测试桥。
