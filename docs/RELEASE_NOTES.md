# 1.0.0rc4 更新记录

## 本次修订

保持行政办公界面、唯一计分引擎、多级总表、一页一图PDF、图片原件与历史留痕、三种部署方式和管理CLI。

- 桌面材料／反馈截屏：用户选择共享源，只截一帧，立即停止全部媒体轨道；预览、裁剪、确认后加入本地队列，用户另行提交。取消、拒绝、粘贴与文件上传保留。
- 统一大表／卡片选择组件：Ctrl/⌘、Shift、矩形框选、双轴边缘滚动、Esc恢复选择、右键及键盘菜单、列筛选排序、明确区分本页与全部队列。菜单复用授权动作，不成为权限旁路。
- 固定连续阅卷队列：一键提交备注和指定状态，成功后下一项；未保存导航提醒、失败保留、冲突不盲重试、最后一项停留。快捷键及触屏按钮同时提供。
- 批量工程移动／回收／恢复、学生班级与启停、合法已有局部材料的人工复核、名单／课程草稿处理与申请处理。服务端批量写入原子提交；只读及不可变历史不增加覆盖删除。
- 计算结果到成果明细，再按ID定位原图片、绑定的名单历史版本或课程；完整成果导出与所选可见字段导出明确区分。
- CSV/XLSX统一有界读取，保留物理行列；未知列、重复身份、公式、非法值和版本冲突给出位置及可下载错误。预览无写入，确认时再校验，错误整批回滚。
- 网页AI：签名、7日期限、工程／身份／原件／规则版本绑定任务包，原图、索引、规则与提示词、22列回填表。外部结论保留web_ai和未人工核对，不覆盖人工结果，不导入总分。
- 单一局部标注验证与个人公开字段白名单；新增human-only student_note。存储哈希完整性、课程Decimal精度、目标身份CAS与SQLite文件句柄关闭补强。
- 外部skill新增逐阶段工作流与诊断说明；annotate必须带实际判断时保存的--context。五份HTML文档及运行时副本同步。

## 清理及兼容

不增加内置模型、后台Agent、微服务、计分副本或任务数据库表。旧阅卷处理器移除，新增职责明确的review-ui、workflow-ui、collections、capture模块；原接口路径、clearledger技术标识、数据卷及.zcp格式保持兼容。数据库模式仍为v1，可空JSON字段缺省为空，不重写历史。

更新前先停止写入、备份并校验，保留.env、APP_SECRET和原数据卷。仅替换旧代码不能保证读写新字段；回滚须恢复匹配版本备份。本轮执行70人合成工程往返，没有重新评审真实学生或承诺所有旧部署均已验收。

## 执行证据

回归、覆盖率、界面、交互、700人导出规模、840行网页AI回填、PDF、文档及本机运维见docs/validation/。具体数量以独立报告为准，未通过的中间尝试不列为通过记录。

新增截图测试使用canvas MediaStream替身，验证真实帧提取、停止、裁剪和排队；没有验收操作系统原生选择器。Chromium业务操作采用离线DOM＋Python真实HTTP桥或ASGI桥，不能代替浏览器原生HTTPS、cookie与反向代理端到端验收。无实际模型准确率、并发峰值或渗透测试结论。Docker、PostgreSQL、systemd、Windows/macOS、TOTP、ClamAV、实体手机、实际Office打印仍须目标环境验收。
