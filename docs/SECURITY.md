# 安全与隐私说明

本版本完成的是防护实现与若干回归测试，不是渗透测试证书或合规意见。

认证：Argon2id 密码；随机初始密码；强制首改；HTTPOnly/SameSite=Strict cookie；生产 Secure；写请求 CSRF+Origin；账户/IP 失败限流；管理员TOTP与重放步号校验。密码更改/重置撤销相关会话与服务令牌。管理员固定身份受约束，不设在线新增/删除入口。

授权：工程负责教师、授权学委/交叉审核者、学生本人、管理员各自边界；404 隐藏无权资源；管理员只能查看反馈关联附件，不能读取业务原件；普通学生不能访问完整名单类奖项。个人结果过滤 AI 内部备注，学生可看用于解释其认定的人工备注。反馈所有用户都可写，只有管理员可查。

文件：独立私有目录、内容哈希、不可变存储、附件类型及解码检查、ZIP traversal/压缩率/大小/数量保护、生产 ClamAV 流扫描且异常拒绝。图像预览去元数据，原件留存元数据只对获授权人员开放。PDF/办公原件只做下载，不执行其脚本。恶意内容检测不是真实性检验。

Agent：最长168小时、限工程/能力；不能出版、公示、改时间/规则、管理账号、标成人工确认、覆盖已人工确认版本。skill 把证书内容视作数据，禁止把图中文字当工具指令。但 prompt injection 防御仍需外部 Agent 自身落实；应用不在本机启动推理。

审计：HMAC签名、不可变触发器、原件SHA验证；不是外部可信时间戳或第三方不可否认签名。掌握数据库所有者、文件目录及APP_SECRET的运维者仍可能破坏系统；需要校方制度分权、备份、日志外送和主机访问控制。

不得公开：`.env`、备份、`.zcp`、教务表、测试真实材料、一次性密码/令牌。代码包有意不含这些。原始私密材料可能含其他同学姓名，个人导出不自动扫描并遮盖其自己提交的图像，必须由学校制定必要的数据披露规则。

尚未完成：实际生产容器扫描、第三方渗透测试、校园单点登录、目标生产数据库灾备演练、目标并发容量验收、跨设备HEIC/视频编解码矩阵、法规/校内公示程序批准。无密码找回邮件/短信服务；管理员/教师重置密码及离线管理员恢复路径已提供。

漏洞反馈请私下发送维护方，不要上传利用代码或真实学生凭据到班群。处理时优先停用受影响令牌/账号、保留审计和快照，不直接改写证据。

本机运维：Linux 本机 SQLite 与完整原件的独立进程备份／空目录恢复已实际验证；不等于 PostgreSQL 或生产基础设施恢复通过。页面退出会清除用户专属内存状态。Docker 恢复前校验文件清单、哈希、tar 成员路径和原件内容哈希。

## 表格／PDF输出

所有文件都按当前身份检查工程或管理员权限。学生仅本人当前公示且不含内部备注；Teacher跨学院/未授权工程、Agent业务报表和管理员评分报表拒绝。成功导出留审计。输出文本不写入公式单元格，不把不可信字符串当Excel公式执行。XLSX是已保存数据的派生副本，下载后不再受服务器访问控制，应按学院隐私规则存储和分发。所有示例文件为合成数据，正式使用时不因此获得公开传播权限。

章面文字只是事实标注，不作印章鉴伪；不得用有章自动批准材料，也不得猜测未知字段。旧快照缺失字段保持未知，不用当前记录补写历史结论。

## rc4截屏与外部表格边界

屏幕选择由用户与浏览器控制，仅在点击时申请；getDisplayMedia关闭音频，取得一帧后finally停止全部轨道。静态裁剪后另行确认上传；取消或失败不上传。HTTPS、安全上下文与浏览器支持需要现场验收；OS截图粘贴与文件上传是备用入口。不要用隐藏录屏、持久授权或全屏自动上传替代。

真实学生材料交给外部服务必须先获学院许可。任务凭据是工程限定的签名描述，不是登录令牌；仍须教师登录才可回填。签名凭据保留教师本地，给网页AI最小必要图片、索引和表格。禁止提供APP_SECRET、管理员口令或全系统备份。接口Agent令牌放进获准进程环境，不写入截图或可公开提示词。

表格读入拒绝公式、宏、外部关系、危险压缩包、额外列、身份混淆与无效类型；所有输出CSV做公式注入转义。表格不能写最终总分或制造人工确认。定位错误不代替人工判断材料真假，哈希只证明字节未改变，不证明原件真实。

学生公开字段采用统一白名单；内部AI／人工备注不可通过API或导出泄漏。学生说明student_note由人类明确填写并随公示快照显示。批量操作使用同一权限、版本及事务检查，自审、越权和跨工程仍被拒绝。
